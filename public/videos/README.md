# Videos del portfolio

Coloca aquí los clips MP4 (h.264, vertical u horizontal) de cada proyecto.

| Archivo esperado | Proyecto |
|------------------|----------|
| `sowa-tattoos.mp4` | Sowa Tattoos |
| `wankamotors.mp4` | Wankamotors |
| `ryu-store.mp4` | RYU Store |
| `adidas-la-salle.mp4` | Adidas La Salle |
| `unimac.mp4` | Unimac |
| `recepciones-evento.mp4` | Local Recepciones |

Para activar el hover-play, añade la propiedad `video: { src, poster }` en
`components/portfolio/portfolio-content.ts`. Mientras no exista el archivo,
la tarjeta muestra la imagen estática (comportamiento original).
